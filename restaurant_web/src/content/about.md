# 关于我们

## 品牌故事

姜胖胖首尔自助烤肉成立于 **2022 年**，总部位于四川成都，隶属于姜胖胖餐饮管理（成都）有限公司。品牌以"原切现拌、新鲜看得见"为核心理念，主打韩式无限量自助烤肉，客单价约 60–80 元，精准锁定 18–35 岁年轻客群。

品牌名中的"姜胖胖"传递亲切温暖的形象，寓意让每一位顾客吃得满足、吃得尽兴。自创立以来，姜胖胖以惊人的速度扩张，截至 2024 年底全国门店已突破 **150 家**，覆盖北京、上海、四川、河南、陕西、浙江、广东等多个省市，成为近年增长最快的韩式自助烤肉连锁品牌之一。

## 环境

餐厅采用姜胖胖品牌标志性的韩国怀旧街景风格，设计灵感源自韩剧《请回答 1988》，以深色木质调为主，搭配暖色灯光与复古韩式街景装饰，营造出温暖热闹的烤肉氛围。店内空间宽敞，涵盖大厅用餐区与独立包厢，能容纳不同规模的聚餐需求。
